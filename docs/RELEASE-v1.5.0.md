# 小红书排版编辑器 v1.5.0 已上线｜公考双底图模板版

小红书排版编辑器 v1.5.0 已完成 Cloudflare 与大陆 OSS/CDN 双轨上线。本版围绕公考内容排版、长文分页和字体视觉对齐做了完整升级。

## 立即使用

- 大陆通道：https://xhsposter.tshzchen.cn/
- Cloudflare：https://xhs-poster-editor.l-yanjunnn.workers.dev/

## 本版更新

1. **新增「公考·山水卷」双底图主题**：第 1 页自动使用封面底图，第 2 页起自动使用内页底图；增删分页后会按页序自动重排。
2. **封面标题颜色可调**：主标题和副标题支持分别输入 HEX 色值，也可以一键恢复模板默认色。
3. **正文工具全部常驻**：编辑器工具栏固定为两行，标题、列表、分隔线、分页、图片等操作无需再展开「更多」。
4. **列表分页更可靠**：在无序或有序列表中插入分页，会生成真正的新页面；有序列表在下一页继续原序号。
5. **按真实字形做中线对齐**：H2 标题与前置竖线、有序列表数字与首行文字会根据实际字体、字号和字重自动校准，预览与高清导出保持一致。
6. **草稿继续兼容**：旧版草稿、旧主题、上传素材和用户字体都可以继续使用，不会被自动改成公考主题。

## 上线验证

- 两条生产入口均已验证 1 / 2 / 5 页公考排版与 Cover/Inner 底图路由。
- 单页 PNG 和多页 ZIP 均保持 `2160 × 3600` 高清尺寸。
- 雅致、极简白、深夜黑三个旧主题及用户字体已完成生产回归。

## 使用提醒

- 工具无需注册，草稿、上传素材、字体和自定义主题只保存在当前浏览器的本地存储中，不会上传服务器。
- 两个网址使用各自独立的浏览器本地数据；在其中一个网址保存的草稿，不会自动出现在另一个网址。
- 更换浏览器、清理站点数据前，请先导出重要成品并保留原图。

欢迎直接打开体验。如发现具体页面、字体或导出结果异常，请保留原草稿并附上截图、使用网址和浏览器版本，便于快速定位。
