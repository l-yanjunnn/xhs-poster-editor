# 小红书排版编辑器 v1.7.0 发布候选说明｜导入文稿与完整导出

> 状态：本地生产候选。实现、自动化和真实浏览器自查已完成；尚未部署、打 tag、归档或发送公告。用户目检确认后再补写生产证据。

## 本版重点

1. **导入 Markdown / 纯文本**：顶栏新增「导入文稿」，支持选择文件、拖放和粘贴全文。先确认结构、页数、封面与发布文案，再生成到一个独立新草稿
2. **生成后继续手动调整**：导入结果进入原有 Tiptap 编辑、撤销和自动保存链，不是只读快照；正文、标题、分页和右栏发布文案都可继续修改
3. **发布文案独立保存**：专用文稿中 `# 正文` 以下内容放在右栏独立卡片，不进入图片正文，不随导出页码复制，也不添加“上篇 / 下篇”
4. **精确处理 17 / 18 / 19+ 张**：18 张是普通图文单篇上传兼容线，不是编辑器生成或导出上限；19+ 仍完整生成到同一草稿
5. **19+ 可以一次完整导出**：全部导出前增加一次本地留存确认，明确完整图片不能作为一篇普通图文一次上传，但不会禁止导出
6. **自选页码**：同时保留范围输入与缩略图多选，二者双向同步；导出文件始终使用原稿页码，升序去重
7. **独立文件夹 + 兼容 ZIP**：支持时选择父目录并创建一个独立子文件夹；不支持目录写入时回退为一个 ZIP。两种方式都不按 18 张分包
8. **中文正文两端对齐**：左侧编辑区和 1080×1800 成品画布正文保持两端对齐，段尾自然靠左；H1/H2/H3 不强制拉伸

## 状态文案

- 1–17 张：`可作为一篇普通图文发布`
- 18 张：`18 张，达到当前普通图文单篇上限`
- 19+ 张：`共 N 张，超过普通图文单篇上限 18 张；仍会完整生成`

18 由 `app/src/lib/productConfig.ts` 集中配置，只表示当前普通图文单篇的高置信兼容上限；不代表小红书所有内容类型的统一限制。原生长文是另一条平台管线，本版没有接入。

## 导出交付规则

- 图片：`01_[文档主题]_cover.png`、`02_[文档主题]_inner.png`，页码至少补两位
- 文件夹：包含主题、导出范围、张数和北京时间；重复导出自动追加 `-02` / `-03`
- 清单：每次附带 `导出清单.json`，记录源页、文件名、交付方式和普通图文兼容判断；发布文案不进入导出包
- 目录：内部逐页生成并写入，文件成功关闭后才记为完成；中断后可在同一页面会话内继续剩余页
- ZIP：只有一个顶层文件夹，不拆成多个生产包；支持原生“另存为”的浏览器可现场修改 ZIP 名称和位置，否则使用浏览器下载
