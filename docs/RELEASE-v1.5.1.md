# 小红书排版编辑器 v1.5.1 发布说明｜高频编辑修复版

v1.5.1 聚焦日常排版中最容易打断节奏的撤销、标题和封面参考区问题，并保持旧草稿、旧主题与导出结果兼容。

## 立即使用

- 大陆通道：https://xhsposter.tshzchen.cn/
- Cloudflare：https://xhs-poster-editor.l-yanjunnn.workers.dev/

## 本版更新

1. **编辑器失焦后仍可撤销**：点击顶栏、画布或画布图片后，Command/Ctrl+Z 仍会撤销最近一次编辑；Shift+Command/Ctrl+Z 和 Windows 的 Ctrl+Y 可安全重做。
2. **不抢普通输入与画布手势**：编辑器正文、普通输入框、弹窗、组合输入、只读标签页和图片拖动继续保留自己的交互；只有历史命令真正成功时才阻止浏览器默认行为。
3. **标题整段语义更清楚**：H1 / H2 / H3 都作用于整段。Enter 新建段落，Shift+Enter 只在当前段内换行；界面已增加常驻提示。
4. **修复标题选区边界**：选区端点落在上一段末尾时，不再把相邻两段一起改成标题；真实跨段选择仍会按预期修改所选段落。
5. **标题范围收敛为 H1–H3**：移除隐藏的 H4–H6 快捷键入口；旧内容中的 H4–H6 会兼容归一为 H3，不会留下下拉框无法识别的标题节点。
6. **公考封面建议内容区更实用**：Cover 保持左右 `x=120…960`，上下调整为 `y=300…1500`；Inner 继续使用独立的 `x=96…984 / y=180…1500`，旧主题不变。
7. **参考层继续保持简洁**：仍为左、中、右、上、下五条线，标签改为“建议内容区”；参考线只在编辑界面显示，不会进入 PNG。

## 使用提醒

- 标题作用于整段；如果要让下一行使用不同样式，请按 Enter 分段。Shift+Enter 只换行，不会创建新段落。
- 公考封面会在小红书信息流中按中心 3:4 检查，重要文字尽量放在建议内容区内；背景图片仍可铺满整页。
- 封面与内页的建议内容区分别配置，没有统一成同一套尺寸。

## 兼容范围

- v1.5.0 与更早版本的草稿、分页、主题、上传素材和用户字体可继续使用。
- 本版不修改公考 Inner、雅致、极简白、深夜黑的内容边界。
- 复杂网格、字体本地化/减重、标题字重档位、结构化封面和 Markdown 导入没有混入本补丁版本。

## 发布验证

发布闭环将对 Cloudflare 与大陆 OSS/CDN 两个入口分别执行版本/资源一致性、公考 1 / 2 / 5 页、旧三主题、用户字体和 2160×3600 导出回归；验证结果在闭环完成后写回本说明。
