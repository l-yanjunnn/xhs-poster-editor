## 这次改了什么

### 封面副标题新增三档微排版

右侧「封面版式」新增「副标题字距」，可选紧凑、标准、舒展。它只影响首图中紧跟第一个 H1 的封面副标题，不改变主标题、内页正文或其他段落。

经三种封面版式的画布与 2160×3600 PNG 目检，本版正式锁定以下值：

| 封面版式 | 紧凑 | 标准 | 舒展 |
|---|---:|---:|---:|
| 左对齐叠排 / 居中海报 | `0em` | 不新增覆盖，继承 v1.10.2 | `0.08em` |
| 小字在上大字在下（kicker） | `0.10em` | 不新增覆盖，继承 v1.10.2 的 `0.18em` | `0.26em` |

标准档是兼容基线：三种版式的 sealed geometry、snapshot 和画布截图与 v1.10.2 real-fixture 严格相同；2160×3600 PNG 只允许最多 0.003% 像素发生 1 色阶的跨运行抗锯齿量化波动。生产标定的变化点全部位于字形边缘，不在副标题；紧凑与舒展只覆盖副标题字距，不另行改变字号、宽度、位置或文本内容。本地 3 版式 × 3 档证据见 [`screenshots/v1.11.0/`](screenshots/v1.11.0/)。

### 「全篇 H1 宽度」命名澄清

右栏原「H1 宽度」改名为「全篇 H1 宽度」，明确它作用于全文所有 H1。此次只改标签文案：`h1Width` 行为不变，左侧工具栏的 H1 编辑功能也没有移动。

## 兼容与边界

- 新建草稿与主题默认使用标准档。
- 旧 V1/V2 草稿、旧内置主题和旧自定义主题缺少字段或字段无效时，统一回落到标准档，保持 v1.10.2 原视觉。
- 有意输入的普通空格、NBSP 与 Shift+Enter 软换行会按原文保存；切换三档不改写副标题文本。
- 本版不新增副标题宽度、自由滑杆、局部字距、自由文本框，也不扩展到内页。
- 本版不改确定性排版算法、分页、安全区，以及 PNG / ZIP / 目录导出算法；导出路径只消费与预览相同的封面样式状态。
