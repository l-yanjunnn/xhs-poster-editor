## 页面布局更清楚，也更可控

右侧新增与「发布文案」「页面与主题」一致的页面布局卡片。先选择页码，编辑预览定位到该页：封面显示偏移滑杆和重置，内页显示默认 / 顶部 / 居中。默认跟随模板保存的位置，顶部对齐 Logo 上缘并为首段预留 Logo 空间，居中保持原模板留白。整篇空格显示单独标明范围。

封面偏移会整体移动文字，三种封面版式与上 / 中 / 下对齐均按实际画布像素生效；修复候选版中居中只移动一半、底部不移动的问题。内页位置独立保存，分页身份、撤销重做与刷新恢复沿用已有文档模型。在内页保存主题时，其当前有效位置成为模板默认；明确的逐页覆盖在切换模板时保留。

新增「超级紧凑」密度；新稿可保留连续空格，旧稿缺省外观与旧密度档位保留。已经被旧版删除的空格不能自动恢复。

## 先确认真实 PNG，再下载

导出弹窗先生成实际 PNG 成品预览，下载复用同一批图片；修改内容或样式会使旧成品失效。一次导出固定页序、样式与资源版本，只克隆需要导出的页。

最终几何、字体、绘制字形和可观测的不透明墨迹分别检查。长封面不再被压缩重叠，画布外裁切阻断；安全区告警须确认。预览/下载同一文件不能替代独立丢字检查。

## 保存与导入更可靠

后退缓存恢复时重新获得写锁并读取最新保存稿件，事务内拒绝旧版本覆盖并保留冲突恢复副本。素材、字体和主题按事务提交成功才报告保存成功。中文粗体边界保留原始空格，Markdown 代码围栏中的标题不再被误提取为封面标题。
