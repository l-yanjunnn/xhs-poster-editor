# Gate 0 诊断报告：CDN 可选字体的生产预览 / 导出 A/B（2026-08-12）

> 只读诊断，线上无任何改动。被测版本 **v1.7.3**（两生产入口同构建）。
> 脚本：`tools/font-gate0/gate0_cdn_fonts_prod.py`（可随时重跑复现；截图 / ZIP / report.json 为运行时产物，不入 git）。
> 对应 HANDOFF §5「⚠️ 待验证疑点」与 `docs/ROADMAP-2026-08-12.md` 的「Gate 0 诊断」行。

## 结论一句话

**「CDN 字体在 prod 导出里可能回退」的疑点不成立**：5 个 CDN 字体（霞鹜文楷 / 站酷小薇 / 站酷庆科黄油 / 马善政毛笔 / 龙藏体）在 Cloudflare 与大陆通道两个生产入口的预览和导出 PNG 中均真实生效。字体本地化（≥v1.9.0）的性质从「修导出缺陷」降级为「性能与可靠性优化」。

## 方法

单页中文 H1「永远的字体诊断样张」，极简白主题；对基线（思源黑体，fontsource 本地化）+ 5 个 CDN 字体逐一：应用 → `document.fonts` 探针 → 预览 `.page` 截图 → 导出兼容 ZIP 取第一页 PNG → 预览 vs 导出的墨迹 IoU（双图归一 270×450、灰度 <140 记墨，交并比）。全程记录 googleapis / gstatic / jsdelivr 请求与 console。

三轮：① Cloudflare 入口（系统代理）；② 大陆通道（Playwright 默认，事后发现仍走系统代理，作废但数据留档）；③ 大陆通道强制 `--no-proxy-server` 真直连 + curl 直连独立复核。

- 两入口 217 个字体请求 **0 失败**，console error 0。

## 生效机制（比结论本身更重要）

1. `collectAllCss()` 确实跳过跨域字体样式表——每次导出稳定出现 2 条 `[exportPng] skipping cross-origin stylesheet` 警告（Google css2 + jsdelivr style.css）。
2. 但 html2canvas 克隆文档里的 `<link>` 标签会在导出瞬间**重新加载** CDN CSS 与 woff2（每次导出都观测到这批请求，全部 200），补上了被跳过的 @font-face。
3. 实测时字体已在预览中使用过 → woff2 在浏览器缓存里，导出期重请求即时命中。**残余风险窗口**：冷缓存 + 慢网下，克隆文档 `fonts.ready` 的 3s 兜底可能等不到直连 gstatic（单 woff2 实测 4–6.5s），理论上可退化。真实用户导出前必然先在预览里看到过该字体（即已缓存），所以此窗口极窄，但它是「导出正确性依赖运行时第三方 CDN」这一架构事实的一部分。

## 直连可达性与加载体积（广州本机网络单点测量）

- 真直连：`fonts.googleapis.com` 200 / 4.3s，`fonts.gstatic.com` 单 woff2 200 / 6.5s——**可达但慢**；`cdn.jsdelivr.net` 200 / 0.55s。地区 / 运营商差异无法由单点外推，仍是记录在案的残余风险。
- 首屏字体请求仅 8 个 CSS ≈ 177 KB、woff2 按 unicode-range 懒加载（首屏 0 二进制）。其中 **lxgw-wenkai-webfont 的 style.css @import 了 6 份分片 CSS（regular/light/bold × 常规/mono）≈ 176 KB**，而应用只用到一两档——这是 ≥v1.9.0 减重的第一个现成目标。
- 单字体首次应用拉 7–8 个 woff2 分片（约 0.2–0.6 MB / 字体）。

## 测试方法论坑（已修进脚本，供其他生产脚本参考）

Playwright 的 chromium 不传 `proxy` 参数时**仍会使用 macOS 系统代理**；「直连」必须 `--no-proxy-server`。现有 `test_prod_deep.py` 注释里的「大陆通道自动直连」实际是假直连——对它本身影响不大（它测同构建回归，不测网络可达性），但任何要测「大陆用户真实网络」的脚本都必须显式加该参数。

## 对 ≥v1.9.0 字体工作的含义

- 不存在需要「当期新补丁版本」修的生产导出缺陷（HANDOFF §5 疑点条款的第一分支不触发）。
- 字体本地化 / 减重按 ROADMAP 走 P2 功能版路径，价值排序：① 消除运行时第三方 CDN 依赖（离线 / 弱网 / 地区差异）；② 首屏 CSS 减重（先砍 LXGW 多余档位）；③ 封死冷缓存慢网的导出退化窗口。
