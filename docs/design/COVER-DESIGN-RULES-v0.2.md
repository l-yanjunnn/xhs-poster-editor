## 断句与层级

1. **主标题先保证完整表达。** 沿用首图第一个顶层 H1 为主标题、紧邻的普通段落为副标题的结构。核心观点留在主标题，补充说明由作者安排在副标题；不自动移动或改写原文。
2. **按完整语义组织行。** 推荐“普通人／可以完整。”，避免“普通人可以完／整。”。这里的“／”仅标记示例换行，不是文稿内容。避免完整词语、固定短语被拆开，以及可避免的孤字、孤标点行；不为凑齐行宽拆坏语义。
3. **尊重作者的显式换行。** Shift+Enter 产生的标题内换行优先保留；不能因字体、字号或主题切换而静默合并。语义建议与作者断句冲突时，由作者决定，不自动重写。
4. **短语保护局部应用。** 现有「短语不拆」适用于明确选中的 1–12 个字符，不能跨换行。不给整段、全部标题或所有粗体自动套用 `nowrap`。它是作者的控制工具，不等于自动中文语义分词。
5. **放不下时明确反馈。** 现有超宽保护可恢复换行并提示。后续交互应指出具体短语与限制，引导作者调整封面独立字号或手工断句；保留全文，不静默删字、裁字或缩字，不通过缩小整篇字号解决一张封面的问题。

示例结构：

```html
<h1>普通人<br>可以完整。</h1>
<p>凭什么我们如此特殊</p>
```

## 字号、字重与验收

- 先固定底图、位置、宽度、字号与字重，仅比较字体；随后再分别比较断句、字号、字重，避免把多个变量的改善归因于一个设置。
- 字号按 1080×1800 画布定义。编辑器缩放视图、完整 2160×3600 PNG 与信息流缩略图分别检查：主标题能否读完整、主副层级是否明确、复杂汉字是否拥挤、裁切后是否仍完整。
- 「加粗」当前为 400/700 两档。本轮不新增 500/600；后续调整须依据实际字体和成品对照决定，不能只凭数值判断。某台设备上不同 CSS 字重可能映射到同一字面；应记录实际字体，不能将本机结论外推到 Windows。
- 预览、分页测量与 PNG 导出必须使用相同的字体、字重、字号、宽度、显式换行及短语保护信息。实现同时验证保存恢复、主题切换与旧草稿兼容。
- 本规则不要求自动重排现有文稿；任何未来自动断句能力都应独立设计、可预览、可撤销。
