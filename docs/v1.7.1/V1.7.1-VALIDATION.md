## 结论

V1.7.1 已把正文、标题和封面副标题改为同一套确定性行级布局。预览先完成断行、光学占宽、水平位置、逐字素 baseline 和逐行装饰，导出只克隆这份已封印快照；字体、布局或 baseline 校准失败都会阻止导出并显示原因。

2026-08-12 的第二轮标点复核不再把问题简化成“压左还是压右”。行级求解器直接测量相邻两枚字形的可见墨迹边缘，把每个标点左右约束合并成连续可行区间：冒号在普通文字之间近似对称；开、闭双引号内侧首选 0.18em、外侧首选 0.22em，并分别保留 0.14em / 0.16em 硬下限；顿号、逗号的文字前距下限提高到 0.15em；`。”`、`”，`、`：“` 等连续标点只共享一份净空。行末宽度、字形原点和可见右缘也由同一联合求解收敛。

## 实现范围

- `deterministicTextLayout.ts`：按字素测量、禁则换行和动态规划断行；把每个标点逻辑框拆成 `leading clearance + ink + trailing clearance`，余差依次分配给双侧标点净空、汉字与数字/拉丁连续串边界、全行统一且有上限的汉字缝。连续标点共享一次 boundary，行末闭标点按可见墨迹右缘悬挂。数字/拉丁串内部字形不拉伸。
- `deterministicTypography.ts`：保留原始 Unicode 与 `strong`、`u`、荧光笔、nowrap、显式换行和列表语义；把每行位置与每行下划线/高亮物化为可克隆 DOM；逐字素测真实 baseline，再规范到行级 canonical baseline。
- `deterministicFontReadiness.ts`：按页面真实使用的 family/weight/style/完整字形样本调用 FontFaceSet；缺字、拒绝、超时或 API 异常均返回显式问题。
- `Preview.tsx`：字体就绪、确定性物化、列表列宽冻结、光学校准和快照封印采用可取消 revision 事务；晚到字体或列表列宽变化会重新生成快照。
- `exportReadiness.ts` / `exportPng.ts`：只接受 `ready + 0 issue + sealed snapshot`；离屏副本仅进行原子 baseline renderer 适配，H2 与列表装饰原样复用预览快照；任何字素超限或缺失都整页失败，不允许“仍然导出”绕过字体/布局错误。
- `canvas.css`：禁用确定性块上的浏览器 justify、letter-spacing 和原生下划线；预览与 html2canvas 绘制同一批绝对几何节点。

## 剩余风险与边界

- Noto/思源核心字体已走本地 fontsource；部分可选装饰字体仍依赖 Google/jsDelivr。离线或 CDN 失败时现在会明确阻止导出，但本次没有把全部可选字体本地化。
- 系统字体 allowlist 以 macOS 为当前目标环境；若未来在 Windows/Linux 自托管，需要补对应字体策略。
- 当前编辑器不支持 `sup/sub` 或非 baseline `vertical-align`；若未来加入，需把语义垂直偏移单独编码，不能被行级 baseline 归一化。
- 用户后续明确授权上线闭环；最终稳定版 v1.7.2 已在 Cloudflare 与大陆 OSS/CDN 两入口完成生产验证。v1.7.1 首次生产门禁发现列表序号相对正文高 12px，保留该历史标签后升版修复，v1.7.2 两入口复测均为 0px。
