# v1.10.2 发布说明

> 2026-08-16，v1.10.2 已完成 Cloudflare 和大陆通道双轨发布。本文保留 v1.10.0、v1.10.1 和 v1.10.2 的版本记录；对外合并公告按用户最终决定，仅包含 v1.10.1 和 v1.10.2。

## 这三个版本改了什么

### v1.10.0：公考封面版式

- 「公考·山水卷」首图新增左对齐叠排、居中海报、小字在上大字在下三种版式，每种都可选上、中、下三档垂直位置。
- 版式只改封面主标题和副标题的画布呈现，不改正文结构，也不影响内页。旧主题和旧草稿缺少新字段时，仍按原来的左对齐上方版式显示。
- 未修改的默认教程切换到公考主题时，首页会换成对应的示例封面，这一步可以撤销。用户改过教程内容后，系统不会覆盖原文。

### v1.10.1：删光草稿后恢复教程

删除最后一份草稿后，编辑器现在会重新建立完整的 5 页使用教程，而不是留下一个空白画布。教程使用默认雅致样式，刷新页面后仍然保留。

### v1.10.2：弹窗、续段和 Code 块修复

- 导入和导出弹窗适配较矮的浏览器窗口。标题与底部操作按钮保持可见，结果区单独滚动。
- 在段落中插入分页，或按 Enter 后紧接着插入分页时，上一页的续段末行会正常铺满版心。真正的段落末行仍保持自然左对齐。
- Code 块中的长中文、URL 和无断点 token 会在固定画布内换行，空格、Tab、空行和手工换行保持不变。编辑区、预览与 PNG 导出结果一致。

同一标题内换行仍使用 Shift+Enter；Enter 表示新建段落。Code 块的本次修复针对横向超宽，如果整块内容在垂直方向超出一页，仍需手动插入分页。
