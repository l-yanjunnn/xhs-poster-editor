# 小红书封面参考线诊断（2026-08-11）

> 状态：复杂网格方案已被用户否决；本文已收敛为简洁安全区方案。用户已于 2026-08-11 确认右侧 Demo 的 `y=300 / 1500` 方案，并已完成 v1.5.1 本地成品目检；当前进入发布闭环。

## 1. 已确认的产品方向

- 用户是设计小白，不应学习栏、栏沟、模块、基线等术语。
- 保留 v1.5.0 原有的五条简洁参考线：左、竖向中线、右、上、下。
- 封面左右边界已经合适，继续固定为 `x=120 / 960`；中线继续为 `x=540`。
- 本轮只重新设计封面上、下边界；内页不跟随修改。
- “裁切参考”和“排版参考”继续独立；所有参考层只在预览显示，不进入 PNG、草稿或撤销记录。
- 不实施 6 栏、纵向模块或可见基线网格。复杂设计规则由工具内部持有，不暴露给用户。

## 2. 平台与本地事实

- 编辑器输出 `1080×1800` 的 9:15 图片。
- 首图中心 3:4 可见区为 `1080×1440`，在源图上的坐标是 `y=180…1620`；上下各 180px 是裁切风险区。
- v1.5.0 基线的公考封面内容盒为 `x=120…960 / y=340…1180`，即 `840×840`。
- v1.5.0 基线的封面底边距为 620px，等于在 3:4 可见区底部额外留出 440px；没有可核验的平台规则要求这么大的固定底部留白。
- 当前小红书官方 App Store 展示图里，发现页卡片的标题、账号和互动数据位于封面图下方；封面图内没有持续占据大块底部空间的固定文字栏。页数或视频标识可能出现在角落，因此四周仍需保留缓冲。
- 公开资料能支持“首图优先按 3:4 检查、重要文字远离边缘、用手机缩略图验证可读性”，但未发现小红书公开的官方安全区像素值；下面的 120px 是编辑器自身的产品规则，不冒充平台规范。

## 3. 已确认方案：3:4 可见区内四周等距 120px

保持横向不变，把现有左右 120px 的规则复用到 3:4 可见区的上下：

- 3:4 可见区：`y=180…1620`
- 上边界：`180 + 120 = 300`
- 下边界：`1620 - 120 = 1500`
- 五条线：`x=120 / 540 / 960`，`y=300 / 1500`
- 新建议内容区：`840×1200`
- 相比当前 `840×840`，可用高度增加 360px，即约 `42.9%`
- 上边只上移 40px；主要修正是下边从 1180 下移到 1500，增加 320px。

这套数字的优势是只有一句规则：**在首图 3:4 可见区里，四周都留 120px。**

## 4. 面向小白的显示方式

- 顶部开关继续叫“排版参考”。
- 蓝色框内标签改为“建议内容区”，不用“网格”“栏”“模块”等术语。
- 四条边界线使用淡蓝实线；竖向中线再淡一档并使用虚线，不加额外标签。
- 橙色裁切层继续叫“首图 3:4 可见区”，与蓝色建议内容区分层显示。
- 页面只给一句提示：`重要文字尽量放在线内；背景图片可以铺满整页。参考线不会导出。`

## 5. 需要明确的边界

`y=300…1500` 表示“重要内容不会被中心 3:4 裁掉并且没有贴边”，不等于每一种背景在整个区域内都同样适合放字。

公考山水底图约从 `y=1300` 开始出现较明显的山水层次，因此长标题和主副标题仍应优先停在上半区；下方新增空间更适合较短副标题、标签、图片或未来的结构化封面元素。背景可读性由主题底图和文字对比度负责，不应被误写成平台裁切规则。

## 6. Demo 与确认结果

- 设计确认：用户采用右侧 Demo v2 的 `y=300 / 1500`，内页暂不跟随修改。
- 可移植实现证据：`docs/design/v1.5.1/xhs-editor-v1.5.1-local-safe-area-cover-v1.png` 与 `docs/design/v1.5.1/xhs-editor-v1.5.1-local-safe-area-inner-v1.png`。
- 最终确认：v1.5.1 本地成品已通过用户目检，用户已授权进入发布闭环。

## 7. 已确认的实现与验收范围

- 公考封面左右仍为 `120px`，只把 top/bottom 从 `340 / 620` 改为 `300 / 300`。
- 内页继续保持 `x=96…984 / y=180…1500`。
- 旧三主题保持原值，不借补丁版本统一版心。
- 参考线与真实内容边界保持一致，避免“线变了但分页/溢出判断没变”。
- 更新 Preview/CSS/overflow/canvas width 相关测试，并回归长标题、副标题、图片、旧草稿页数和导出。
- 33%、40%、50% 预览缩放时坐标误差不超过 1px。
- 排版参考开启/关闭后的导出 PNG 必须像素级一致。

结构化主标题/副标题槽位、三套封面版式和有限位置调整仍属于后续 v1.6 候选；Markdown/自动编排仍属于 v1.7。
