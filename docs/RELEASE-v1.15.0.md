## 这次更新了什么

- **六类右栏工具**：文字、页面、外观、图片、发布、记录，各自展开和收起；选中文字或图片不会自动切走当前分类。字体直接显示在文字类，发布文案保留独立编辑、复制和草稿保存。Logo 在外观内直接选择目标页，与页面布局共用页码。
- **系统字体置顶**：H1、H2、H3、正文的字体下拉首项都是「系统字体 · 随设备」。macOS 优先苹方，Windows 优先微软雅黑，其余设备使用本机无衬线回退。仅引用本机字体，不分发苹方或微软雅黑字体文件；换设备后字形和换行可能不同。旧选项、现有主题与旧稿默认字体不迁移。
- **封面独立字号**：「文字 → 封面主标题字号」提供跟随原规则、108、126、144 px。无需选择文字，仅改变第 1 页第一个 H1；内页与其他文字保持各自字号规则。草稿、新主题与主题缩略图保存此设置；旧数据缺省继续跟随。
- **两种强调样式与独立五色色板**：整块底色、划线荧光笔可分别搭配青绿、紫、黄、粉、蓝。已有标记单独改变样式、颜色或透明度时保留另外两项；支持标题、正文、跨行、撤销重做与草稿恢复。旧紫色底色和既有透明度保持兼容。
- **窄窗口可达**：窄窗口用正文、预览、字号与设置三个工作区切换；宽窗口保留三栏，右侧工具收起后释放预览空间。窄窗口适配不代表所有手机、浏览器均已验证。

## 怎么用

调整封面大小：打开「文字」，直接选择 108 / 126 / 144 px；点「跟随原规则」恢复原有主题计算。没有封面 H1 时，先在第一页添加主标题。三种封面版式均使用同一个显式字号值。

调用本机字体：在「文字 → 整篇字体」的任一层级选择第一项「系统字体 · 随设备」。这不需要导入字体文件；换机器编辑时仍需查看实际换行。

强调关键词：先选中标题或正文中的词，再到「文字 → 关键词强调」选择样式、颜色和透明度。紫色可以划线，青绿也可以用作整块底色。缺省底色为紫色 25%，缺省划线为青绿 50%；选区已有的另外两项属性不会因单项修改被重置。

单独设置 Logo：打开「外观 → Logo → 设置 Logo 所在页」，选页后调整「本页 Logo 显示」。页码与「页面 → 设置当前页」共用；滚动预览不会改目标页，请以「仅第 N 页」为准。既有整篇范围、封面三档位置与公考主题约束保持。

点右上角「导出 PNG」后，仍先生成真实成品预览，再下载同一批已验证图片；正文或样式改变后须重新生成。画布与 PNG 尺寸规则仍为 1080×1800 / 2160×3600。
