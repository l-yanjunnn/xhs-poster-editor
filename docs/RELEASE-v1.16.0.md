# v1.16.0 · 百草路撸猫战神主题与独立排版示例

**2026-10-10 北京时间：双入口发布、归档、使用说明同步与本人飞书公告均已完成。** 最终测试和生产操作的准确范围见文末记录；不外推为全部设备验收。

## 这次更新了什么

- **已有「雅致」更名为「百草路撸猫战神」**：保留主题 ID `builtin-elegant`、宣纸底纹、猫环 Logo、配色和左对齐叠排；封面垂直位置默认「中」。封面主标题、全篇 H1 / H2 / H3 与正文统一使用「系统字体 · 随设备」。其他内置主题不变。
- **默认封面方向为纯大字**：本主题缩略图只展示一个主标题，人工分成「普通人」「可以完整。」两行，不默认放副标题。副标题功能仍可使用；给现有稿件套主题只调整样式，不删除或替换正文、副标题和作者手动换行。
- **新增独立排版示例**：「导入文稿 → 示例文稿 → 百草路撸猫战神 · 排版示例」提供三页可编辑内容：纯大字封面、正文分段与小标题、引用与少量加粗。内页明确是可替换的排版说明，不作为账号作者文章。三页只是示例长度，实际文章页数随内容确定。
- **封面主标题字体可单独设置**：「文字 → 封面主标题字体」可以选系统字体、预设字体、已导入的用户字体，或「跟随全篇 H1 字体」。仅改变第一页第一个顶层 H1，内页 H1 和其他文字不随之改变。设置贯通草稿、恢复日志、自定义主题、主题缩略图、预览测量与 PNG 导出。

本主题的整体字号仍为 40 px；跟随原规则时 H1 / H2 / H3 / 正文为 90 / 56 / 44 / 40 px，封面独立字号默认仍为「跟随原规则」，没有改成 126 px。既有 108 / 126 / 144 px 选项保留，标题粗体 700、正文 400 的规则保持。

## 怎么用

**试用完整示例**：打开「导入文稿」，在「示例文稿」点击「百草路撸猫战神 · 排版示例」，检查三页内容后确认生成。编辑器先保存原草稿，再将示例和本主题样式一起保存为独立新草稿。旧稿可从草稿列表重新打开；取消导入不会换稿，重新选择普通文件或粘贴文稿也不会携带示例主题。原有五页工具教程继续保留。

**让自己的文章使用新主题**：在主题库或「外观」的主题选择中套用「百草路撸猫战神」。这一操作只改样式，不把示例文字写入文章。已有草稿不会因升级自动改字体；希望使用新默认时，主动重新套用主题即可。

**只改封面字体**：打开「文字」，在「封面主标题字体」中选择字体。选「跟随全篇 H1 字体」可以清除独立覆盖；随后封面随整篇 H1 字体变化。封面字号仍由相邻的独立字号控件调整。

**按完整意思分行**：标题里用 Shift+Enter 手动换行，尽量让完整短语留在同一行。本轮没有自动语义断句，没有通用 Markdown 新语法，也不会按文件名判断主题。示例的两行标题是预先人工排好的内容；既有「短语不拆」仍由作者主动选用。

## 兼容与使用边界

- 旧 V1 / V2 草稿和已保存的用户主题缺少独立封面字体字段时，继续跟随原全篇 H1；不会自动改名、居中或切换系统字体。已有正文、强调标记与手动换行保留。新建默认稿和主动套用本主题使用新的系统字体默认值。
- 系统字体只引用本机字库：macOS 优先苹方，Windows 优先微软雅黑，其余情况回退本机无衬线字体；不分发这两种字体文件。换设备后字形、字宽和换行可能变化，需重新查看成品。本轮 macOS 已本地验证，Windows 尚未真机验证。
- 仅导出内页时，不因封面独用的自定义字体不可用而阻止导出；包含有主标题的封面时，仍检查该字体。原有文字完整性、字体与几何校验继续执行。
- 草稿恢复后主题名称可能显示为「自定义样式」，保存的完整样式仍会恢复；本轮没有新增主题身份持久化。新建内置示例完成时显示对应主题名称。
- 草稿、上传素材与字体仍保存在当前浏览器。换浏览器、换入口域名或清缓存不会自动带走这些数据；重要原文、素材和成品请另存本地。
- 既有 Logo 整篇范围、逐页显示及封面位置，以及真实 PNG 预览后下载流程继续保留，不作为 v1.16.0 新增功能。独立批次重新渲染不承诺全像素一致；同一批成品预览与下载继续复用同一 PNG。
