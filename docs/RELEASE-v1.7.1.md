# 小红书排版编辑器 v1.7.1 发布准备说明｜预览与导出确定性排版

> 状态：本地候选，等待用户视觉验收。未提交、未推送、未部署、未打 tag、未归档、未发送公告；线上仍是 v1.7.0。

## 本版解决什么

v1.7.1 修复了“编辑器预览正常、导出 PNG 后数字下沉、下划线错位或正文重排”的问题。预览与导出现在共享同一份已测量、已封印的行级布局，不再分别依赖 Chromium 与 html2canvas 的中文 justify、letter-spacing 或 baseline 行为。

- 非末两端对齐行的右边缘严格齐平；
- 汉字间距按整行统一微调，不再把余差集中到少数几个字缝；
- 全角标点优先吸收余差，但压缩依据是实际墨迹与双侧安全净空，不再把统一 `0.5em` 当作视觉正确答案；原字符与语义不变；
- 冒号、顿号、双引号按左右相邻字形的实际墨迹距离分别求解；普通文字夹冒号近似对称，引号内侧保持语义附着、外侧保留呼吸感，`。”`、`”，`、`：“` 等连续标点只共享一份净空；
- 行末标点用透明悬挂保持可见右缘齐平，同时保留合适的入侧字距；
- 汉字与数字/拉丁串边界是第二弹性来源，数字字形本身不拉伸；
- 封面“4”、内页“2026”与汉字统一 baseline；
- 单行和跨行下划线按真实行逐条绘制；
- 字体、布局或 baseline 校准失败时明确阻止导出。

## 本地验证

- 40 个测试文件 / 385 项自动测试、类型检查、ESLint 与 Vite build 全绿；
- 最小回归覆盖中文、标点、数字/Latin、粗体、荧光笔、nowrap、显式换行、列表、单行/跨行下划线和极端行宽；
- 预览/导出独立像素配对的行、列投影 lag 均为 0；H2 竖条顶部差为 0 px、bbox 最大差 1 px；
- 真实 19 页完成 19/19 原生 2160×3600 导出，保存完整 19 条逐页快照/基线/渲染哈希记录，source/canvas snapshot 逐页一致；
- 最小回归直接测量每个标点边界：双引号内侧首选 0.18em（硬下限 0.14em）、外侧首选 0.22em（硬下限 0.16em），逗号/顿号文字前距下限 0.15em，冒号左右差为 0；行末闭标点与连续标点联合求解，可见墨迹右缘误差为 0 px；
- 保留第 1、2、3、5、19 页原生 PNG 供人工抽查。

完整指标、视觉证据和剩余风险见 [`v1.7.1/V1.7.1-VALIDATION.md`](v1.7.1/V1.7.1-VALIDATION.md)。
